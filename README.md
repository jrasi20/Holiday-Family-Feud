# Christmas Bible Survey Showdown

An installable, host-led Christmas Bible party game for families, churches, and small groups.

## Game format

- 10 Bible-centered rounds grounded in Matthew 1-2 and Luke 1-2
- 2 wholesome holiday "Joy Break" bonus rounds
- Two-team scoring, strikes, steals, round bank, and timer
- Sound and haptic feedback
- Responsive portrait and landscape layouts for iOS and Android
- Installable PWA with offline support

The point values are original gameplay values, not the results of a scientific survey.

## Local development

```bash
pnpm install
pnpm run dev
```

## Production build

```bash
pnpm run build
```

The static GitHub Pages build is written to `docs/`.
